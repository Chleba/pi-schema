# Pixel-art QA checklist

- [ ] Projection matches the game.
- [ ] Pixel density matches neighboring assets.
- [ ] Silhouette reads at normal gameplay zoom.
- [ ] Nearest-neighbor sampling is used.
- [ ] Camera and transforms do not introduce unwanted blur.
- [ ] Pivot/anchor is consistent across animation frames.
- [ ] Sprite sheet frame bounds are correct.
- [ ] No atlas bleeding or unintended transparent fringe.
- [ ] Faction color remains readable for color-vision differences.
- [ ] Selection/collision footprint is defined separately.
- [ ] Building stages line up exactly.
- [ ] Asset source and license are recorded.
